# Stim Pi (mozzarella) — Notes

**Pi:** mozzarella, 192.168.10.102, user `vruser`  
**Role:** PsychoPy stimulus display via DLP projector on parabolic screen

## Files deployed to mozzarella

```
~/rig/
  task.py              ← main trial loop + PsychoPy window
  stim_generator.py    ← pre-generates stimulus arrays per session
  protocol.py          ← shared config dataclass (copied from Mac)
  config.yaml          ← session config (deployed per session)
~/rig/calibration/
  compute_warp_map.py  ← generates warp_map.npz from rig_geometry.yaml
  rig_geometry.yaml    ← physical screen measurements
  warp_map.npz         ← output: pixel lookup table for visual angles
~/stims/
  {session_id}/        ← pre-generated stimulus frames (per session)
```

## DLP Projector Startup Sequence

Must run before task.py can open a PsychoPy window.

1. **Set GPIO 0-21 to ALT2** (DPI parallel video output):
   ```bash
   for i in $(seq 0 21); do pinctrl set $i a2; done
   ```
2. **Enable video buffer** (GPIO 25 high):
   ```bash
   pinctrl set 25 op dh
   ```
3. **Initialize DLPC3436** (DLP controller chip) for external parallel input:
   ```bash
   cd ~/dlp && python3 init_parallel_mode.py
   ```
   - `~/dlp/init_parallel_mode.py` is NOT part of VRFarm repo
   - It configures the DLPC3436 via I2C to accept parallel RGB video
   - Must run AFTER GPIO ALT2 is set and video buffer is enabled
4. **Start X11 server** (if not already running):
   ```bash
   sudo X :0 -ac > /tmp/xorg.log 2>&1 &
   ```
5. task.py uses `DISPLAY=:0` to render on the X11 session

This entire sequence is automated by `rig_setup/rig_setup_ui.py` (Setup button)
and `experiment/experiment_ui.py` (Connect stim Pi button).

## PsychoPy Configuration

- Monitor name: `dlp_projector`
- Resolution: 1920x1080 fullscreen (currently hardcoded in task.py)
- GPU: V3D (hardware), 24-bit visuals
- **pyglet MUST be 1.5.27** — 2.x fails to create GL context under FKMS+DPI
- psychopy installed with `--no-deps` + manual dependency install

## ZMQ Sockets (task.py)

| Socket | Port | Direction | Purpose |
|--------|------|-----------|---------|
| ROUTER | 5570 | cheddar connects here | Receives LICK, REWARD_DONE, SYNC_PULSE from worker |
| PUB    | 5571 | Mac subscribes | Publishes trial events, lick events, state changes |
| PULL   | 5581 | Mac pushes commands | Receives START, STOP, REWARD from experiment_ui |

## Warp Map

- Generated by `calibration/compute_warp_map.py` using `rig_geometry.yaml`
- Stored as `~/rig/calibration/warp_map.npz`
- If missing, task.py falls back to centered stimulus at (960, 540)
- Generate via "Generate warp map" button in rig_setup_ui.py
