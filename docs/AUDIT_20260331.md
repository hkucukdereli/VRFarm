## Critical Issues (Blocks Functionality)

### 1. MONITOR_LICKS / MONITOR_PHOTODIODE not handled in worker.py
- `experiment_ui.py` sends `MONITOR_LICKS` and `MONITOR_PHOTODIODE` commands
- `worker.py` command loop does not handle them — commands are silently ignored
- **Impact:** UI "Monitor licks" and "Monitor photodiode" buttons are non-functional
- **Fix:** Add handlers in worker.py main loop

### 2. SYNC_PULSE events not forwarded by task.py
- `worker.py` sends `{'event': 'SYNC_PULSE', ...}` via ZMQ DEALER to task.py
- `task.py worker_thread()` only handles READY, LICK, REWARD_DONE — drops SYNC_PULSE
- **Impact:** Photodiode timestamps never reach the Mac dashboard
- **Fix:** Add `elif evt == 'SYNC_PULSE': state.publish(...)` in task.py

### 3. Camera MJPEG parameter mismatch in worker.py
- `Camera.mjpeg_stream(self, every_n=2)` does not accept `preview_res`
- Flask route passes `preview_res=(640, 360)` → TypeError at runtime
- **Fix:** Add `preview_res` parameter or remove from call site

## High Priority (Data Loss Risk)

### 4. HDF5 write errors uncaught
- `task.py write_trial()` has no error handling for disk-full or I/O errors
- Could lose trial data silently

### 5. lick_poll() exception handling too broad
- Catches generic `Exception`, prints, continues — I2C bus hangs go undetected

### 6. Config reload path issue (FIXED)
- Was using relative path that didn't resolve on reload
- **Fixed:** experiment_ui.py now resolves absolute path and rig JSON from config `rig.name`

## ZMQ Event Flow (Current State)

### Working paths:
```
LICK:     worker → DEALER → task.py (ROUTER) → lick_queue → PUB → Mac SSE → browser raster
REWARD:   Mac → PUSH → task.py (PULL) → ROUTER → worker (DEALER) → solenoid pulse
TRIAL:    task.py → PUB → Mac SSE → browser stats
```

### Broken paths:
```
SYNC_PULSE:       worker → DEALER → task.py → [DROPPED, no handler]
MONITOR_LICKS:    Mac → PUSH → worker (PULL) → [DROPPED, no handler]
MONITOR_PD:       Mac → PUSH → worker (PULL) → [DROPPED, no handler]
```
